
# Library Management System (OOP)

## About
This is a simple Library Management System built using Python and Object-Oriented Programming (OOP).

It allows users to manage books by adding, viewing, issuing and returning them.

## Features
- Add new books with title and author.
- View all available books.
- Issue books from the library.
- Prevent issuing an already-issued book.
- Return issued books.
- Display book availability status.

## Concepts Used
- Classes and Objects
- Constructors (__init__)
- Methods
- Lists
- Loops and Conditional Statements
- Encapsulation through object attributes

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

   python library_management.py
